# Checkout issue reports

These reports preserve the Checkout audit findings from [`yuki/checkout-session-bug-finder`](https://github.com/stripe/stripe-ios/tree/198e6b8ee2d240aad5c01384ac2a256f8920a500) at commit `198e6b8ee2d2`. The reproduction tests, example-app scenarios, compiler checks, and audit notes remain available at that revision; the reports describe results from that audit.

Screenshots linked by the reports are preserved in `images/`. Use [bug report guidance](../bug_report_guidance.md) when adding a report, and check this folder for an existing report of the same root cause first.
